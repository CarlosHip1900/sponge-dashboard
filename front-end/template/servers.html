Groups

Groups represent isolated network contexts inside your infrastructure. Servers within the same group can see each other, transfer players, and share logic such as matchmaking or scaling rules.

For example, a BedWars group may include multiple game instances that only interact with each other, without affecting other game modes like Factions or Lobby.

Server Templates

Templates are predefined server configurations that allow you to deploy Minecraft servers instantly without repeating setup steps. They define the server type, version, plugins, JVM flags, resource limits, and startup behavior.

By using templates, you can scale your network faster, maintain consistency across servers, and reduce human error when deploying or auto-scaling game instances.
